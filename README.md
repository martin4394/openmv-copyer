# openmv-copyer
A small program to copy the content of a folder to the OpenMV on Ubuntu Linux.

## How to set it up
1. Make sure that you have `git`, `python3-pip`, `python3-venv` and `python3-tk` on your Ubuntu System.
2. Run `git clone https://github.com/martin4394/openmv-copyer.git`
3. Navigate in the folder `openmv-copyer/`
4. Run `bash ./setup.sh`


## How to run it
To run it normally, type `bash ./start.sh`
