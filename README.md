# openmv-copyer
A small program to copy the content of a folder to the OpenMV on Ubuntu Linux.

## How to set it up
1. Make sure that you have `python3-pip`, `python3-venv` and `python3-tk` on your Ubuntu System.
2. Run `python3 -m venv env` in the folder
3. Install the `requirements.txt`
4. To start the project, run `start.sh`
